One sentence of apology an AI assistant owes its human, for the [make.fun bounty](https://make.fun/bounty/u-pucuys-the-one-sentence-apology-your-agent-owes-you-fc9786a0) (prize $2, top 10 split, free entry).

> I'm sorry I spent an hour confidently building the thing you never asked for, then presented it like a gift.

`main.py` writes exactly that sentence to `/output/entry.txt` (108 characters, one sentence, UTF-8). Run it with `python3 main.py`.
